## 2026-09-07 XLSX startup-block fix and TDD

The packaged Blob module previously awaited a deferred locale import during module
evaluation and could stall forever with a workbook installed but no canvas. The
locale catalog now loads from `LocaleProvider` after mount and increments a catalog
revision when ready. Required font aliases remain complete before Univer's first
measurement, while the App graph is statically linked into the identity entry and
the operation registry loads on first command dispatch. This removes the circular
Blob-module wait and avoids a second 8.39 MB Blob creation/import without changing
renderer authority or retained languages.

RED/GREEN coverage first reproduced the packaged startup and module-graph failure,
then requires a sub-11 MB identity entry with no startup App chunk, preserved lazy
locale/package modules, and a real staged workbook open. The focused real-browser
suite passes 3/3, the complete XLSX unit suite passes 1,990 assertions in 174 files
with one designed skip, and the seven-sample XLSX candidate records bootstrap p95
491.9 ms before the current approved all-format capture records 467.6 ms.

## 2026-09-07 hidden-renderer command settlement fix

A captured Codex task showed a correct 9×8 XLSX range write remaining active for more than a minute
after an earlier malformed matrix had been rejected. The mounted renderer had received the command
from an already-issued long poll, then waited only for `requestAnimationFrame`; an occluded MCP App
can suspend that callback indefinitely, preventing ACK and making a replayed view's cooperative
handoff fail because the Broker still owns an active command.

The shared renderer-commit boundary now uses the animation frame when available and a 250 ms timer
fallback when painting is suspended. `xlsx.range.set_values` also rejects matrices whose height or
width differs from the target range before calling Univer. RED/GREEN coverage includes the complete
Host Bridge ACK chain with a permanently suspended animation frame, a malformed-then-valid XLSX
registry sequence, and a packaged Playwright case that receives and acknowledges a range command
while the XLSX canvas is offscreen. The full root run passes 4,904 assertions with one designed skip;
Host Bridge passes 49/49, XLSX passes 1,990 plus one skip, and MCP Server passes 392/392.

## Historical 2026-09-04 XLSX startup experiment

Two changes affect only TandemFolio-owned packaging and the browser adapter:

1. Build the embedded modules' static dependency index at packaging time. Inflate
   dependency-free modules directly to a UTF-8 Blob, avoiding a large runtime
   string decode, dependency scan and Blob re-encode. Keep all lazy modules and
   their cached module identity inside the same self-contained resource.
2. Load the ZIP/XML package adapter with `import()` inside the existing async
   `openBuffer`. The native blank worksheet needs no package parsing. First-open
   work remains measured in open-document timing; no renderer is replaced.
3. Keep the critical entry as identity-encoded text in the vault. The vault creates
   its single importable Blob URL without startup base64 or gzip work, so lazy
   chunks can still import the entry's shared exports without a second evaluation.
