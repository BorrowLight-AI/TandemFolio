# Domain docs

This is a single-context repository.

## Before exploring

- Read `CONTEXT.md` at the repository root.
- Read relevant accepted decisions under `docs/adr/`.
- Use `docs/README.md` to locate protocol, migration, roadmap, provenance, and runbook documents.
- If a referenced file is absent, proceed silently.

## Vocabulary

Use the domain terms defined in `CONTEXT.md`. Avoid synonyms that its glossary explicitly rejects.

## Architectural decisions

Surface conflicts with accepted ADRs explicitly. Do not silently override an accepted decision; changing one requires a superseding ADR.
