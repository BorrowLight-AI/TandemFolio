## Extraction boundary

The initial source-preserving extraction copied the upstream community checkout while excluding:

- `.git` and Git worktree metadata;
- `ee/` in its entirety;
- `node_modules/` and generated dependency state;
- `out/`, `dist/`, `release/`, `.electron-vite/`, and `coverage/` build outputs;
- `.DS_Store` platform metadata.

Enterprise `ee/` source was not used as a reference implementation, was not copied, and is not a permitted future migration source.

This document separates current filesystem provenance from the accepted product target. ADR 0003
requires selective restoration of the pinned non-AI renderer sources. All five format-local
retained-command producer baselines are now closed. XLSX has all 76 permitted pinned renderer files
and 123 Registry operations; PPTX has the pinned 80 permitted paths plus selectively admitted
source-current native engine/render/editor work and 81 operations; PDF has all 33 permitted paths
and 25 operations. Markdown and DOCX likewise retain their community renderer structures and own
22 and 103 operations. Lossy states fail
closed and open-ended Agent dispatch is absent. Earlier R6-01 pass records below
are historical; current release authorization is recorded in
[release verification](../../release/validation.md).
